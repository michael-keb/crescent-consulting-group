# Crescent Consulting Group — deployment folder

This folder contains the website source ready for an online deployment.

## Deploy with a Node-capable host

1. Upload this folder to Vercel, Netlify, Render or another host that supports Next.js/Vite-style Node builds.
2. Install dependencies with `npm install`.
3. Build with `npm run build`.
4. Start with `npm run start` if the host needs a start command.

The production website is already live at https://common-ground-workplaces.mkeb.chatgpt.site/.

The public contact area uses the phone number only. The enquiry form still accepts a visitor email address for replies.
